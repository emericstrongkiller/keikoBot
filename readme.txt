First, clone the keikoBot repository in the Aquabot-Competitor repo

To launch the simulation, use the launch file in folder 'launch': aquabot.launch.py
-> To choose a map: modify the argument 'world' line 29 in the launch file or change the argument when starting in terminal

The default command we used:

ros2 launch ./src/Aquabot-Competitor/keikoBot/launch/aquabot.launch.py
